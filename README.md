# Sim Game I – Mittelsteinzeit (spielbare Fassung)

Aufbau- und Dynastie-Simulation in der Ego-Perspektive, um 9000 v. Chr. – im Browser spielbar:
**https://aresthes.github.io/simgame-spiel-Proto/**

Dieses Repository enthält nur die fertig gebaute Fassung des Spiels (Three.js), keinen Quellcode. Es wird am Ende jeder
Entwicklungssitzung aktualisiert. Steuerung: WASD gehen, Maus schauen, E untersuchen, G mitarbeiten/aufheben, Q Auftrag/zeigen,
L hinlegen, T Zeitraffer, Esc Menü (Grafik, Lautstärke, Spielstände).

Klänge: Mixkit (Mixkit-Lizenz) und Pixabay (Pixabay-Inhaltslizenz) – nur zur Nutzung im Spiel, keine Weitergabe der Einzeldateien.
